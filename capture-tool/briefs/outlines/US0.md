## Step outline: greeting

1. Greeting types in `src/lib/greeting/types.ts` (the user's name and preferences the greeting needs).
2. The greeting formatter in `src/lib/greeting/greeting.ts`: one function that turns a user into a greeting.
3. A helper in `src/lib/greeting/batch.ts` that greets several users at once, using the formatter.
4. Unit tests in `test/greeting.test.ts`, a short README section, then `npm test`.
